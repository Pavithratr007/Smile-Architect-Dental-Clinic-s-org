# 🦷 Smile Architect Dental Clinic

A modern, mobile-friendly website for **Smile Architect Dental Clinic**, located in Hebbal, Mysuru. It presents the clinic's services and helps patients find and contact the clinic easily.

🔗 **Live Demo:** https://smile-architect-dental-clinic-7140.ai.studio

## ✨ Features
- Clean, responsive design for mobile and desktop
- Services overview: pediatric dentistry, preventive care, orthodontics, implants, oral surgery and cosmetic treatments
- Google Maps integration for clinic location and directions
- Supabase backend for storing patient enquiries/appointment data

## 🛠️ Tech Stack
- **Google AI Studio**: app generation and development
- **ChatGPT**: planning, content and prompts
- **Google Maps**: location and directions
- **Supabase**: database and backend

## 🚀 Getting Started

1. Clone the repository
```bash
   git clone https://github.com/YOUR-USERNAME/smile-architect-dental-clinic.git
   cd smile-architect-dental-clinic
```
2. Install dependencies
```bash
   npm install
```
3. Create a `.env` file and add your keys
